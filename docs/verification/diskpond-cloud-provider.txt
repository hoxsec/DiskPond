## Delivered

- **DiskPond Cloud** appears immediately after **S3 compatible** in both create
  and connect provider pickers, with the owner's DiskPond icon and searchable name.
  Vault cards, previews and connection settings retain its distinct identity.
- Reuses the full S3-compatible form: endpoint, bucket, access key ID, secret key,
  region, session token, prefix and both explicit insecure connection settings.
  HTTPS and certificate verification are enabled by default.
- **Open DiskPond Cloud** opens `https://cloud.diskpond.com` in the browser.
  A preview-mode URL-handler fix avoids parsing an absent development origin.
- The new `DISKPOND_CLOUD` local provider identifier maps to engine type `s3`.
  Native IPC validates its configuration; saved credentials use the existing
  OS-protected/session-only connection path. No repository-format migration or
  automatic relabeling of existing S3 connections is performed.
- Hostnames and root HTTP(S) URLs normalize to the engine's hostname/port format.
  Embedded credentials, paths, queries, fragments and conflicting URL/TLS settings
  are rejected with localized field errors. Credentials, region, prefix and token
  retain their exact values. HTTP requires the explicit insecure option.
