DiskPond's **first stable public release** brings account-free, encrypted desktop backups to **Windows 10/11 x64**.

## Highlights

- Encrypted, incremental, versioned backups to your own storage, with deduplication and compression.
- Multiple vaults; local/external drives, mounted NAS, S3-compatible storage, B2, GCS, Azure, SFTP, WebDAV and Rclone integrations.
- Backup schedules, retention, exclusions and pinned versions.
- Snapshot browsing, selected-file/folder recovery and ZIP restore.
- Backup comparison with added/changed/deleted paths and before/after metadata.
- A separate Activity tab for retained backup history, plus light/dark/system themes.
- New-release banner and **Check for updates** in Settings, linking to GitHub releases.
- Fixed the untranslated `comparison.title` label on a fresh launch, in both the history toolbar and backup menu.
- Refreshed README with real application screenshots, features and installation links; obsolete root service-setup files removed.

## Install

Download **DiskPond-Windows.exe** and follow the [Windows installation and recovery guide](https://github.com/hoxsec/DiskPond/blob/v0.1.0/docs/windows-release.md). The installer is unsigned. SHA-256 checksums and matching application/core sources are attached.

Updates are notification-only: download and install from GitHub. Scheduled backups require DiskPond to remain running, including in the tray.

## Scope

This release ships Windows x64. macOS/Linux delivery, exhaustive provider/platform certification, encrypted setup export/import and complete durable failure/cancellation history remain on the roadmap. Activity shows retained snapshots and separately labeled latest known issues. Inherited startup/URI entries can remain after uninstall; see the installation guide.
