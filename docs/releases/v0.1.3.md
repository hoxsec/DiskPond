## In-app updates

- Download updates inside DiskPond, then choose **Restart and install** when backups and restores are idle.
- View download progress, size and speed; cancel and retry downloads.
- Read **What's new** without leaving the app.
- Use **Remind me later** to hide that version's banner for 24 hours.
- Review the latest 50 local update attempts in Settings. Installed outcomes are confirmed after relaunch; failures, cancellations and interrupted or unconfirmed attempts remain distinct.
- Downloads and restarts are user-triggered. Automatic update checks can still be disabled.

### Updating from v0.1.2 or earlier

Install this version using **DiskPond-Windows.exe** from this release. Those versions use the previous external update flow; in-app updating is available after installing v0.1.3.

### Platform and verification

Windows 10/11 x64, unsigned. Core/repository formats are unchanged. Focused updater and keyboard/UI checks passed locally, including live backup/restore activity guards and 32 matching restored file hashes. Release CI also checks installer replacement, real updater download/install/relaunch and post-update recovery. Live provider, other-platform and exhaustive upgrade certification remain deferred.
