## What's new

- **RustFS bucket quotas:** S3-compatible vaults can now show **Bucket quota remaining** using RustFS's quota-statistics API. Uses the saved connection; the access key needs `s3:GetBucketQuota` permission. The value covers the entire bucket, including other vaults/prefixes, and may lag recent writes.
- **SFTP available space:** compatible servers now report destination filesystem space through `statvfs@openssh.com`, with saved credentials and host-key verification. This is available filesystem space, not necessarily your user quota.
- Exhausted destinations report **0 B**. Missing quota configuration reports **No bucket quota**; unsupported endpoints/extensions remain **Not reported**, and failed reads show **Unavailable**.

Amazon S3 and other providers without a supported quota API do not have a universal free-space reading. Live RustFS/SFTP provider validation remains pending; focused protocol/security tests and the Windows installed backup/restore check cover this release. The backup engine and repository format are unchanged.

## Updating

Download `DiskPond-Windows.exe`, finish active backup/restore operations, quit DiskPond and run the installer. Existing installations can find this release through **Settings → Check for updates**.
