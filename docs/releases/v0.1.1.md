## What's new

- **Storage available** now appears alongside protected data, files and directories in each vault overview. Local, external and mounted network destinations report free space on their storage volume/share. The value refreshes every 30 seconds while the overview is active and when you return to it. Other providers show **Not reported**; failed reads show **Unavailable**.
- **Compact Activity rows** keep the folder, vault, completion time, size/file count and outcome visible. Expand an individual backup or latest issue for full details and its backup-history link.
- **Windows development fix:** build and development commands now support standalone `pnpm.exe`, including nested script invocations.

Available space is shared with other data on the destination drive; it is not a per-vault allocation. The backup engine and repository format retain their existing versions.

## Updating

Download `DiskPond-Windows.exe`, finish active backup/restore operations, quit DiskPond and run the installer. Existing installations can find this release through **Settings → Check for updates**.
