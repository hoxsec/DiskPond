## Website and product showcase

- Added the DiskPond prelaunch website source: product pages, Windows downloads, guides, pricing and email enquiries.
- Refreshed the README and website with nine real app views in light and dark themes, covering vaults, schedules, browsing, restore controls, comparison, activity and storage selection.
- Showcased all 11 storage connections, including local/external/network drives, S3-compatible storage, B2, GCS, Azure Blob, SFTP, WebDAV and Rclone.
- Added a release check of the installed desktop package to keep website files out of the Windows installer.

**The Windows installer is desktop-only.** Website pages, pricing copy and product screenshots are included in the repository/source archive and use a separate static website build.

DiskPond Cloud is coming soon: 500 GB at €5/month including VAT, or €45/year. Cloud actions are email enquiries; hosting, checkout and storage provisioning remain pending. The free desktop app continues to support account-free backups to your own storage.
