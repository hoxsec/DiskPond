# Inherited hosted API

This retained BlinkDisk account, billing and configuration-sync service is outside DiskPond's desktop runtime and build. Its upstream branding, service identifiers and database configuration do not represent a DiskPond-operated API.

DiskPond uses an account-free local workspace. See the [root README](../../README.md) and [PLAN.md](../../PLAN.md), X01–X05.
